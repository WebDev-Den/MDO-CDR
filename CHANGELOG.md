# Changelog

## 0.1.0 - 2026-04-08

Initial workspace release.

- Added a modular Rust workspace around `file_defender` and the supporting `defender-*` crates.
- Shipped media-focused CDR pipelines for images, GIF, APNG, audio, MP4, OGG, and WebM flows.
- Added FFI protobuf models and a Swift bridge example for client integration.
- Added tenant policy hot-reload, signed and HMAC snapshot import paths, and key rotation support.
- Added attack simulation, real-world simulation, fixture generation, and workspace parity coverage.
- Added benchmark targets, fuzz harnesses, packaging validation, and stricter CI quality gates.
